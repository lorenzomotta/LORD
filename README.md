# Lord

Programma per scrivere relazioni con testi, tabelle e immagini, e per esportarle in Word.

## Aggiornamenti

Le copie installate, all'avvio, chiedono se scaricare una versione più nuova.

Per pubblicarne una:

1. Alza il numero di versione negli stessi tre file: `src-tauri/tauri.conf.json`, `package.json` e `src-tauri/Cargo.toml`. Per esempio da `0.1.0` a `0.1.1`.
2. Salva le modifiche su GitHub.
3. Crea il contrassegno con lo stesso numero, per esempio `v0.1.1`, e invialo. GitHub compila l'installer e le app installate lo vedono al prossimo avvio.
